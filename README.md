# fanta26

Assistente automatico per la gestione di una rosa Euroleghe Fantacalcio (sistema Mantra): forma dei giocatori, difficoltà della prossima partita, momento delle squadre, disponibilità e copertura TV su Sky / NOW, recapitati su Telegram tramite n8n.

Stato: **disegno del progetto**. Nessun codice ancora.

- [docs/01-disegno-progetto.md](docs/01-disegno-progetto.md) — obiettivi, architettura, fonti dati, flussi n8n, roadmap e decisioni aperte.
